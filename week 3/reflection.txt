Self-Reflection: Why is it better for calculate_tax() to return a value instead of printing it directly?

If calculate_tax() just prints the tax amount, that is the only thing it can ever do.
But if it returns the tax amount instead, the caller gets to decide what to do with it -
print it to the screen, save it to a running total, or write it to a file.

For example, if the manager suddenly wants the tax written to a file instead of shown
on screen, I would not need to touch calculate_tax() at all. I would only need to change
the code that calls it, so it writes the returned value to a file instead of printing it.
If the function printed the tax directly, I would have to go inside the function and
rewrite it. Returning a value keeps the function reusable for many different situations.
